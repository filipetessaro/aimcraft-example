# Aimcraft Demo

Playable Windows demo of **Aimcraft**, a first-person shooter kit for Unreal Engine in C++: procedural weapons,
a server-validated shooter, penetration by surface, a Tarkov-style inventory, a body in seven parts with stamina,
vaulting, menus and LAN sessions. It is the plugin's own example game, packaged as a Shipping build with UE 5.8.

**Download:** [Aimcraft_Demo_Windows.zip](https://github.com/filipetessaro/aimcraft-example/releases/latest/download/Aimcraft_Demo_Windows.zip)
(238 MB). No engine needed.

1. Unzip and run `AimcraftDemo.exe`.
2. Play starts the example map alone. Host Game and Find Games play with a friend on the same network.
3. `HOW_TO_PLAY.txt` in the zip has the keys and the controller buttons, and what to try.

Docs: https://apps.tessaroapps.com/aimcraft/docs/
